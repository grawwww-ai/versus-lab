# ⚔️ VERSUS · Open Archive

> Repositorio público oficial del canal de YouTube **VERSUS**.

Aquí se publicarán el código fuente íntegro, prompts, capturas y razonamientos (*Chain of Thought*) generados en un solo intento por modelos de Inteligencia Artificial para cada episodio.

Podrás auditar cada respuesta, ver cómo resolvieron los retos a ciegas y descargar o jugar con el código en tu propio ordenador.

### 🛡️ Reglas y Filosofía
1. **Un solo intento:** Los modelos no reciben retroalimentación ni segundas oportunidades.
2. **Sin trampas ni edición:** El código que ves en este repositorio es exactamente lo que devolvió la API.
3. **Métricas reales:** Tiempos de streaming, costes en dólares y nota asignada por el juez con rúbrica técnica.
